# Español compartido

Estado: **aprobado para `SpanishSpain` y `SpanishAmerica` en la versión
0.5.115**.

Por decisión del usuario, las dos variantes de español de Cuphead usan
exactamente el texto original del mod, sin diferencias regionales.
